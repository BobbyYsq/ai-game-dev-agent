# AI Game Development Agent

Language:

- [Chinese](README.zh-CN.md)
- [English](README.en.md)

This repository contains a local FastAPI control plane for Godot prototypes. The dashboard creates standalone Godot projects with the vendored Hastur editor plugin enabled, manages local API keys, runs a single-composer LLM + Hastur chat workflow, generates image references, and provides a project-local Git review/commit/restore workbench.
