# AI Game Development Agent（MVP v0.2）

## 项目简介
这是一个面向 Godot 原型开发的应用层 AI 工作流平台。

## 它能做什么
- Windows/macOS 一键启动。
- 在 UI 中配置 LLM/API Key。
- 生成 Godot 项目骨架、文档、脚本与评审报告。

## 它不能保证什么
不保证一次性生成完整商业游戏。

## 快速开始
- Windows：双击 `start_windows.cmd`
- macOS：双击或运行 `start_macos.command`（可能需要先 `chmod +x start_macos.command`）

详情见 `docs/zh-CN/quickstart.md`。
